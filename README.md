# 本地视频流水线（local-video-pipeline）

把一段稿子做成一条竖屏视频——**真人出镜的口播、全动画的、混着来，都可以**（不是非要录口播）。

识别、配音、剪辑、动画、合成，全部在你自己的电脑上跑完。

画面上靠两个动画引擎：**HyperFrames 和 Remotion**，哪个顺手用哪个。

生成环节不花钱：模型都在你机器上跑，不调用任何云端生成 API，素材不上传。

> 不过要说准确一点：如果你是通过**云端 Agent**（ChatGPT / Claude / DeepSeek / Kimi 这类在线助手）来指挥它干活，**Agent 自身的对话可能产生费用或受条数限制**，你发给它的文字跟随对应服务的隐私政策。想真正全程离线：用本地跑的 AI，或者照着手册自己敲命令。

---

## 这是什么

一个**给 AI 用的技能包**（说明书 ＋ 操作手册）。你把整份发给你的 AI，它照着上面的步骤带你从零把流水线跑起来——检查配置、装环境、做片子，每一步都会先告诉你。

### 能做成什么样的片子（不是非要录口播）

- **真人出镜的口播**：你录好，它来剪（剪废片、长停顿），动画做辅助；
- **全动画片**：不用录任何真人素材——画面全由动画引擎做，就是抖音上很火的那种动画视频；
- **混着来**：真人为主、动画补理解。

声音都可以是**录的**，也可以是**合成的**（可复刻音色）。

它按六个环节干活：

| # | 环节 | 干什么 |
|---|------|--------|
| 1 | 稿 | 你写，或者你说一段、它帮你整理；录好的口播也能直接用 |
| 2 | 声音 | 有录音的：识别成文字 ＋ 字级时间戳；要配音的：本地合成人声（可复刻音色） |
| 3 | 剪辑 | 有录像素材才走这步：剪废片、长停顿（全动画片跳过） |
| 4 | 动画 · 音效 | HyperFrames / Remotion：SVG 动画、文字动画、简单动效（全动画片靠它出画面）；音效按需加 |
| 5 | 合成 | FFmpeg 拼接、加字幕（要的话）、导出 |
| 6 | 输出 | 竖屏成片（1080×1920） |

### 额外加装（默认不装）

- **AI 出图**（ComfyUI ＋ 千问 Image 2.1）——需要画面素材时；
- **AI 出视频片段**（MiniMax H3 这类）——需要"动起来的画面"时（这种工具有的本地跑、有的走云端——走云端的素材会离开本机，用前先确认）；
- 这两样最吃显卡，**默认不碰**，有额外需要再加。

---

## 硬件要求（大概就好）

**默认这套不需要大配置——一台还行的电脑就行，16G 内存左右就能跑。**

- **内存**：16G 舒服；8G 是能用的最低线——渲染动画会自动切「省内存模式」，慢一点，但稳；
- **有显卡**：识别、配音跑得更快；6G 级显存用小档，8G 起可以上大档，更稳；
- **没显卡**：走 CPU 也能用，速度慢一些；
- **真正吃显卡的是"额外加装"那两样**——默认不装，不用为它操心。

软件三样：**Node（22 或更新）、FFmpeg、Python**——第 0 步里有查法。

## 装它（三步）

### 第 0 步 · 检查电脑配置

用你系统的命令行（Windows 的 PowerShell / macOS、Linux 的终端），查这四条：

```bash
node -v        # 有版本号 = 装了；提示"找不到命令" = 没装
ffmpeg -version
nvidia-smi     # 有 NVIDIA 显卡才有输出；没独显会报错，这是正常的
python3 --version   # 识别、配音的模型靠它跑（有的 Windows 上是 python --version）
```

内存、动画工具、模型这几样不用你操心——AI 接手后会一起查。看到报错不用慌，交给你的 AI 带你走。它会告诉你：**你的配置是什么、适合哪档模型、还缺什么。**

### 第 1 步 · 安装技能 + 下载模型

**装技能**，两种路子：

- 支持技能目录的 AI（Hermes / Claude Code / Codex 等）：把**整个文件夹**放进技能目录；
- 普通在线 AI（ChatGPT / DeepSeek / Kimi 等）：把 `SKILL.md` 发给它当手册（它跑不了你电脑上的命令，会把每步要敲的东西写给你）。

> ⚠️ 三件东西缺一不可：`README.md`（说明书）、`SKILL.md`（干活的手册）、`LICENSE`——**别只拿 README**，干活的本体是 `SKILL.md`。

装好后对它说一句：**「帮我装本地视频流水线的环境」**，剩下的它带你走。

**下载模型**：模型不会替你下载（好几个 G，自己下最稳）——下到**约定目录**（默认：技能文件夹下的 `models/`，AI 会告诉你确切位置）。先让 AI 告诉你下哪档：

- 显卡大（8G 显存起）→ **1.7B 档**
- 显卡小 / 没显卡 → **0.6B 档**

然后去 **ModelScope**（国内快）或 **Hugging Face** 搜官方名字：

| 模型 | 干什么 | 说明 |
|------|--------|------|
| Qwen3-ASR-1.7B / Qwen3-ASR-0.6B | 识别：转文字、出字级时间戳 | 大档 / 小档，二选一 |
| Qwen3-ForcedAligner-0.6B | 字级对齐（时间戳靠它） | 两个档都要 |
| Qwen3-TTS | 语音合成（可复刻音色） | 要配音才下；**大档选 1.7B、小档选 0.6B** |

下好后，AI 会带你装一次「跑模型要用的依赖」（照官方说明来），再做一次最小测试。

⚠️ **用官方模型，别用第三方打包的"精简版"**——那种经常砍掉组件（比如字级对齐），装完看着能用，字幕和动画对不上。

> 额外加装的 AI 出图要用千问 Image 2.1（Qwen-Image 2.1）＋ ComfyUI——默认不装，有需要再加。

### 第 2 步 · 装好了，怎么用

对你的 AI 说一句：

> **「帮我做一条视频」**

它会先**自动检查一遍配置**（你的机器适合哪档、还缺什么，都先告诉你），然后一步一步往下走：稿子 → 声音 → 剪辑（有录像才走）→ 动画 → 合成 → 出片。

**每个环节都会先汇报再动手**：检测结果、安装进度、干到哪了——它都会主动说。你不用盯着，它说一句你听一句就行。

## 常见坑（真踩过的）

1. **配音要一句一句合**。语音合成对长度有上限，一次念一大段会**悄悄丢尾巴**——不报错，你以为念完了，其实后面没声。做法：按句切成小段分别合成再拼；复刻音色时每段都要带**同一份参考录音**，不然每段像不同的人念的。
2. **动画渲染吃内存**。内存不大的机器（8G 上下）渲染时，引擎会自己切到"省内存模式"——变慢但更稳，这是正常现象，不是坏了。渲染期间别同时开浏览器、游戏、别的大程序。
3. **渲染带声音可能报错**。有些旧版 FFmpeg 缺动画工具要用的功能，整条渲染会被拦下（画面本身没事）。两个办法：升级 FFmpeg；或者两步走——先渲无声画面，再用 FFmpeg 把声音合进去。
4. **有的元素会"被吞"，还不报错**。动画里某些写法（描边字、某些滤镜）会让元素直接不出画面，自动检查也查不出来。别只看"检查全过"——先渲一小段样片用眼睛看，确认没缺东西再全量渲。
5. **中文 / 空格路径会坑人**。有些工具（尤其 Windows 下的老程序）读不了中文路径，报错还看不懂。中间文件尽量放纯英文、无空格的目录。
6. **别一上来就上大档**。显存不够硬跑大档，会慢到怀疑人生。让 AI 按你的配置选档；跑着不对劲再换小档。

---

## 它不做什么

- **默认不做 AI 出图、AI 出视频片段**——那两样是"额外加装"，有需要再加；
- **不替你写稿**——稿子是你的，它负责把它做出来；
- **不自动装东西、不代下模型**——要装什么、下什么，先问你；
- **不自动发布**——成片躺在你电脑上，发不发你定。
